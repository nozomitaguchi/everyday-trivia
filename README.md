# 日常の設計トリビア

身の回りのものを見ると「なぜそうなっているか」「どう使われているか」が推し量れる、設計の意図にまつわるトリビア集。

## 構成

- `trivia/` … 1ネタ1ファイル。出典を確認できたもの
- `inbox.md` … まだ出典を確認できていないネタの置き場
- `images/` … 自分で撮った写真のみ（他サイトの画像は入れない）

## 1ネタのフォーマット

```markdown
---
title: タイトル
tags: [ジャンル, ...]
---

## 見るとわかること
## なぜそうなっているか
## 出典
```

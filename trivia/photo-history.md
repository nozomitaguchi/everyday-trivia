## 見るとわかること

写真のもとは、暗い部屋の壁にあけた小さな穴。穴を通った光が、反対の壁に外の景色を逆さまに映す。これを「残す」方法が1820〜30年代のフランスとイギリスで生まれ、1888年に「ボタンを押すだけ」のカメラ、1975年にデジタルカメラができた。

## なぜそうなっているか

### カメラ・オブスキュラ（暗い部屋）

- 暗い部屋や箱に小さな穴をあけると、穴を通った光が反対側に、外の景色を**逆さまに**映す。ラテン語で「暗い部屋」という意味の「カメラ・オブスキュラ」と呼ばれ、「カメラ」という言葉のもとになった
- アリストテレス、イブン・アル＝ハイサム（965〜1038年ごろ）、レオナルド・ダ・ヴィンチがこのしくみを知っていたといわれる。ルネサンスの画家は、映った景色をなぞって絵をかいた
- でも映った像は、光がなくなれば消える。残すことはできなかった

### 像を「残す」発明

| 年 | だれが | 何をしたか |
|---|---|---|
| 1816年 | ニエプス（フランス） | ネガ（明暗が逆）の像を作ったが、光に当たるとすぐ消えた |
| 1826年 | ニエプス | カメラ・オブスキュラで景色を写し、今も残る**いちばん古い写真**を作る |
| 1829年 | ニエプスとダゲール | 2人で研究を始める（ニエプスが亡くなるまで） |
| 1835年 | タルボット（イギリス） | 紙の上に、消えにくいネガの像を作る |
| 1839年 | ダゲール | 銀の板を使う「ダゲレオタイプ」を発表。世界初の実用的な写真術とされる |
| 1841年 | タルボット | ネガから何枚でも焼き増しできる「カロタイプ」の特許。写す時間も大きく短くなった |
| 1851年 | アーチャー | ガラス板に薬をぬる湿板（しっぱん）写真 |
| 1861年 | マクスウェル | 赤・緑・青の3色で、初めてのカラー写真を見せる |

- ダゲレオタイプは1枚しか作れない。タルボットの**ネガ→ポジ**の方法は、1枚のネガから何枚でも写真を作れて、フィルムカメラの基本になった

{{fig:negative-positive}}

### ボタンを押すだけ

- 1888年、アメリカのイーストマンが、だれでも使える箱型カメラ「コダック No.1」を売り出した。宣伝文句は「**あなたはボタンを押すだけ、あとは私たちがやります**」
- 1948年、エドウィン・ランドが、その場で写真が出てくるポラロイドカメラを売り出した

{{fig:kodak-button}}

### デジタルカメラ

- 1975年、コダック社のスティーブン・サッソンが、光を電気に変える部品（CCD）を使った最初の電子カメラを作った。白黒で、画素は**たて100×よこ100**（1万個）だけ
- 今のスマホのカメラは、1000万画素をこえるものがふつう（→[写真はどうやって撮れるのか](photo-digital-camera.md)）

{{fig:sasson-pixels}}

### 日本の写真

| 年 | できごと |
|---|---|
| 1848年 | オランダ船で、ダゲレオタイプが長崎に伝わったとされる |
| 1850年代 | 川本幸民ら蘭学者が、幕府や藩の仕事として写真を研究 |
| 1857年 | 薩摩藩主・島津斉彬（しまづ なりあきら）の写真が撮られる。国内に残る数少ない成功例で、重要文化財 |
| 1860年代 | 湿板写真が広まり、日本人の職業写真家が生まれる |
| 1934年 | 写真フィルムを国産にするため、富士写真フイルムができる |

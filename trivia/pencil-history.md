## 見るとわかること

鉛筆の芯に、鉛（なまり）は入っていない。それなのに「鉛の筆」と書くのは、黒鉛が見つかったころ、人々がそれを鉛の仲間だと思いこんでいたから。今の芯（黒鉛と粘土を焼き固めたもの）は、戦争で黒鉛を輸入できなくなったフランスで、1795年に考え出された。日本では、江戸時代のはじめに徳川家康が持っていた鉛筆が残っていて、明治の中ごろに国産の工場ができた。

## なぜそうなっているか

### 鉛筆がなかったころ

- 中世ヨーロッパでは、黒鉛ではなく本物の鉛で、写本の下書きの線を引いていた。レオナルド・ダ・ヴィンチやデューラーは、銀の棒で紙をこする「シルバーポイント」で素描した

{{fig:before-pencil-silverpoint}}

- 江戸時代の日本では、字は筆と墨で書いた。明治になっても、低学年の子どもは「石盤（せきばん）」という黒い板に、ろう石を細く削った「石筆（せきひつ）」で書いて練習した。安い洋紙と子ども用の鉛筆が広まると石盤はへり、都会では1930年代に、全国では1950年代に消えた（世界大百科事典）

{{fig:before-pencil-slate}}

- 黒鉛そのものは、アステカの人々が何百年も前から印をつけるのに使っていた。ヨーロッパでは1400年代のはじめにドイツのバイエルンで見つかった

{{fig:graphite-aztec-bavaria}}

### ボローデールの黒鉛と「鉛」の思いちがい

- 16世紀、イギリス北部の湖水地方、ボローデールで、混じりものがほとんどない純粋な黒鉛のかたまりが見つかった。大英図書館は1564年としているが、イギリスの文化財の記録（ヒストリック・イングランド）は、見つかった年はわからず、いちばん古い採掘の記録は1540〜41年だとしている

{{fig:borrowdale-mine}}

- あまりに貴重で、盗みや密輸が商売になるほどだった。武装した盗賊におそわれたあと、1752年にイギリス議会は、黒鉛の鉱山に勝手に入ることを罪とする法律を作った。大きな鉱脈を掘り当てると、値段を高く保つために鉱山を何年も閉じた。1800年ごろからは坑道の入口の上に見張り小屋が建ち、銃を持った見張りの前で黒鉛をえり分けた（ヒストリック・イングランド）

{{fig:borrowdale-guardhouse}}

- 人々はそれを、鉛の鉱石（方鉛鉱）の一種だとまちがえ、「プランバゴ（鉛のようなもの）」「ブラックレッド（黒い鉛）」と呼んだ。ドイツ語の鉛筆 Bleistift（ブライシュティフト）も「鉛の棒」という意味で、同じ思いちがいから来ている

{{fig:graphite-lead-mistake}}

- 1779年、スウェーデンの化学者シェーレが、それは鉛ではなく炭素だと確かめた。1789年、ドイツの鉱物学者ヴェルナーが、ギリシャ語の「グラフェイン（書く）」から「グラファイト」と名づけた。呼び名だけは「鉛」のまま残り、日本語の「鉛筆」にもつながっている（→[鉛筆のことば](pencil-words.md)）

{{fig:graphite-named}}

### ひもを巻いた棒から、木の軸へ

- 黒鉛のかたまりは、やわらかくて折れやすく、そのままでは手が黒くなる。そこで最初はひもで巻いて持ち、次に、くりぬいた木の棒に差しこむようになった。これが木の軸の鉛筆の始まり（大英図書館）

{{fig:pencil-early-forms}}

- 1565年、スイスの博物学者コンラート・ゲスナーが、化石についての本に、筒の先に黒鉛を差しこんだ筆記具の木版画をのせた。鉛筆をえがいた、今わかっているいちばん古い絵とされる

{{fig:gessner-1565}}

- 今わかっている中でいちばん古い鉛筆の実物は、1630年に建てられた木造の家から見つかったもの（大英図書館）

{{fig:oldest-pencil-1630}}

- ドイツのニュルンベルクは、鉛筆づくりの町になった。1662年、フリードリッヒ・シュテッドラーは、市から「鉛筆づくりは鉛の切り出し職人と大工の仕事」として願いを断られたが、同じ年の教会の記録に「鉛の切り出し職人」として名を残している。1761年には、近くのシュタインでカスパー・ファーバーが鉛筆を作りはじめた（今のファーバーカステル）

{{fig:nuremberg-pencil-makers}}

### 戦争が生んだ「粘土を混ぜる芯」

- フランス革命のあと、イギリスと戦争していたフランスは、イギリスの船に港を封鎖され、ボローデールの黒鉛を輸入できなくなった。鉛筆が手に入らなくなり、政府の要人カルノーにたのまれたのが、ナポレオンの軍に仕えていた科学者ニコラ・ジャック・コンテ

{{fig:france-blockade}}

- コンテは1795年1月7日、「人工の鉛筆」の特許を出した。ふつうの黒鉛の粉に粘土をまぜて高い温度で焼き、杉などの木の半分の筒2つで包む。大英図書館は、焼く温度を1900°F（約1040℃）としている（フランス特許庁 INPI）

{{fig:conte-clay-mix}}

- しかも、粘土と黒鉛の割合や焼き方を変えるだけで、芯のかたさを変えられる。今のHやBの段階（→[鉛筆の芯は何でできているか](pencil-lead.md)）は、この発明の上にある。コンテ自身は数字で硬さを表し、数が大きいほどやわらかかった

{{fig:conte-numbers}}

### 長さをそろえ、機械でたくさん作る

- 1840年ごろ、ドイツのローター・ファーバーが、鉛筆の長さを「7インチ（17.78cm）」にしようと言い出した。今の日本のJISの「172mm以上」につながる長さ（日本筆記具工業会、→[鉛筆のかたち](pencil-shape.md)）

{{fig:pencil-7inch-hand}}

- アメリカでは、1827年にジョセフ・ディクソンが会社をつくり、1分間に132本の鉛筆を作る機械を考えた。1872年には1日に8万6000本を作っていた（ディクソン・タイコンデロガ社）

{{fig:dixon-machine}}

- 1858年、アメリカのハイメン・リップマンが、鉛筆のおしりに消しゴムをつけた鉛筆の特許をとった。ところが1875年、アメリカの最高裁判所は、「鉛筆と消しゴムは、いっしょにしても別々に働くだけで、新しい働きは生まれない」として、この種の特許を認めなかった（レッケンドーファー対ファーバー裁判）

{{fig:eraser-pencil-1858}}

### 少しずつ今の形にした人たち

| だれが・いつ | 何をした |
|---|---|
| ボローデールの鉱夫たち（16世紀） | 純粋な黒鉛を掘り、ひもや木で包んで使う |
| ゲスナー（1565年） | 木の筒に黒鉛を入れた筆記具を絵に残す |
| コンテ（1795年） | 黒鉛の粉と粘土を焼く芯。硬さを変えられる |
| ローター・ファーバー（1840年ごろ） | 長さを7インチにそろえようと言い出す |
| ディクソン（1872年） | 機械で1日8万6000本 |
| 眞崎仁六（1887年） | 日本で鉛筆工場をつくる |

{{fig:pencil-inventors}}

### 日本へ：家康の鉛筆から、国産の鉛筆へ

- 静岡の久能山東照宮には、徳川家康（1542〜1616年）が持っていた鉛筆が残っている。日本に残るいちばん古い鉛筆で、重要文化財。家康の遺品の筆箱から見つかった。黒鉛はスペイン領だったメキシコのもので、軸はオークの木。全長114mm（コトバンク）

{{fig:ieyasu-pencil}}

- だれが家康にわたしたのかは、資料でちがう。久能山東照宮の解説（観光庁の多言語解説）は、黒鉛がメキシコ産なので「家康に会ったスペインの使者のひとりがおくったと考えられる」とし、コトバンクの百科事典の解説は「オランダ人が献上した」としている。先がすり減っているので使われたことはわかるが、軸に削ったあとがないので、あまり使われなかったと考えられている

{{fig:ieyasu-who-gave}}

| 年 | できごと |
|---|---|
| 1878年（明治11年） | 眞崎仁六（まさき にろく）が、パリ万国博覧会で鉛筆を見て、国産化を思い立つ |
| 1881年（明治14年） | 井口直樹が手作りした鉛筆を内国勧業博覧会に出す。国産鉛筆の最初とされる |
| 1887年（明治20年） | 眞崎が東京・内藤新宿に眞崎鉛筆製造所をつくり、水車を動力に製造を始める（今の三菱鉛筆。工場生産の始まりを1886年とする資料もある） |
| 1901年（明治34年） | 逓信省（いまの郵便や電話の役所）に正式に採用され、ようやく軌道にのる。創業から14年 |

{{fig:japan-pencil-table}}

### みてみよう

鉛筆の軸の刻印や箱を見て、どの会社の鉛筆か見てみよう。今つかっている鉛筆の会社が、何年に始まったかを箱やサイトで調べて、年表のどこに入るか予想してみよう。消しゴムのついた鉛筆があれば、それは1858年の特許の形。

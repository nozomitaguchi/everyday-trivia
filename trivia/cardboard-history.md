## 見るとわかること

波の形に折った紙は、最初は箱ではなく、イギリスの紳士がかぶるシルクハットの内側に貼るものだった。「段ボール」という名前は、日本でこの紙を作り始めた井上貞治郎がつけた。「ボール」は英語の board（板）がなまったもの。

## なぜそうなっているか

### 年表

| 年 | できごと |
|---|---|
| 1856 | イギリスのヒーリーとアレンが、波形に折った紙の特許をとる。男性用のシルクハットの内側に貼るためのもので、波形の溝がついた2本のロールに紙を通す、手回しの簡単な機械で作った |
| 1871 | アメリカのアルバート・ジョーンズが、波形の紙を、びんなどこわれやすい物を包む紙として特許をとる |
| 1874 | アメリカのオリバー・ロングが、波形の紙の片側に平らな紙（ライナー）を貼って強くする特許をとる |
| 1881 | アメリカのロバート・トンプソンが、ライナーつきのダンボールの特許をとる。会社は機械で動く貼り合わせ機（シングルフェーサー）を作った |
| 1895 | アメリカで、とぎれずに作り続けられる機械（連続コルゲーター）が初めて作られる |
| 1903 | アメリカの朝食用のシリアルの会社が、ダンボール箱を初めて使い、荷物を送る箱として認められる |
| 1909 | 日本で井上貞治郎が東京・品川の借家で作り始め、「段ボール」と名づける |
| 1913 | 井上がドイツ製の機械を輸入し、たくさん作れるようになる |
| 1916 | アメリカで、2枚重ねのダブルウォールが初めて作られる |

### 包み紙から箱へ

はじめの50年近く、波形の紙は「包む」「すきまを埋める」ための紙だった。片側にライナーを貼ると強くなり（1874年）、両側に貼ると板のようにかたくなって、箱の材料になった。1890年代には、機械で休まず作り続けられるようにもなった。

### 日本では「緩衝紙」から

明治のころ、日本の包装には電球を包む紙などが使われていたが、クッションの力が弱かった。いっぽう、ドイツから化粧品を輸入するときに使われていた紙は、波形の段がついていてよく弾んだ。井上貞治郎はこれを国産にしようと、品川の借家に波形ロールの機械を据え、2か月ためして、段のそろった紙を作りあげた（1909年秋）。従業員は2人だった。機械と作り方は実用新案として認められた。

### 名前の由来

「ボール紙を材料に、段々にしわを寄せたもの」だから「段ボール」。ボール紙は、わらのパルプで作った板のような紙で、「ボール」は英語の board（板）がなまった言葉。井上はいくつかの候補から、言いやすいものを選んだという。

英語では corrugated board（コルゲーテッドボード、波形にした板）という。工場の機械の「コルゲーター」も、この corrugate（波形にする）からきている。

井上が1920年に作った会社「聯合紙器（れんごうしき）」は、いまの「レンゴー」。「聯」の字は、段を連ねたダンボールの形に通じるとされる。

## 6〜9歳むけ

なみの かたちの かみは、さいしょは はこじゃ なかったんだ。

いまから 170ねんくらい まえ、イギリスで できたよ。せの たかい ぼうしの、うちがわに はる かみだったんだ。

そのあと アメリカで、びんを つつむ かみに なったよ。たいらな かみを はると つよく なって、はこに なったんだ。

にほんでは、いのうえ ていじろうさんが つくりはじめたよ。「だんだんの ついた ボールがみ」だから、「だんボール」と なまえを つけたんだ。

なぜ「ボール」なのかな。えいごで いたの ことを「ボード」と いうよ。それが なまって「ボール」に なったんだって。

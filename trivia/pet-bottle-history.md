## 見るとわかること

ペットボトルのもとになったPETは、1941年にイギリスで、服の繊維を作ろうとして生まれた。それを炭酸の入れものにしたのは、アメリカのデュポンの技術者ナサニエル・ワイエス。洗剤のボトルにジンジャーエールを入れて冷蔵庫に入れたら、一晩でふくらんで棚にはさまった、という実験から始まった。日本では1977年のしょうゆが最初で、500mlの飲みものが出たのは1996年。

## なぜそうなっているか

### その前は：びんと缶と急須

- 日本では昔から、使ったびんを返して、洗ってまた使う「リターナブルびん」が根づいていた。酒屋や集団回収で集めたびんを「びん商」が引き取って洗い、分ける。ビールびんの回収は99%にもなり、一升びんは日本酒にもしょうゆにも使い回される。ビールびんは8〜10年くらい使われる

{{fig:pb-returnable}}

- 緑茶は、急須でいれて家で飲むものだった。伊藤園が10年の研究のすえ、1985年に「缶入り煎茶」を出して外で飲めるようにした。しかし温かい缶は、熱くなりすぎて飲みにくいという声があった

{{fig:pb-teapot-can}}

### PETが生まれる：1941年、イギリス

- 1930年代の終わり、アメリカのカロザース（デュポン）が作ったナイロンに負けない合成繊維さがしが続いていた。カロザースのチームはポリエステルでは強い繊維を作れず、ポリアミド（ナイロン）へ移っていた

{{fig:pb-nylon-race}}

- 1941年、イギリス・ランカシャー州アクリントンの研究室（キャリコ・プリンターズ協会、布に柄を印刷する会社の団体）で、レックス・ウィンフィールドと助手のジェームズ・ディクソンが、テレフタル酸とエチレングリコールから繊維になる樹脂を作った。これがPET

{{fig:pb-whinfield}}

- 戦争中だったのですぐには発表されず、特許だけが出された。1946年にICI（イギリスの化学会社）が工場を決め、アメリカでの権利はデュポンが買った。繊維の名前は、ICIが「テリレン」、デュポンが「ダクロン」。PETは1948年にポリエステルとして市場に登場した、とPETボトルリサイクル推進協議会は書く

{{fig:pb-terylene-dacron}}

### ボトルにする：ワイエスの冷蔵庫

- 1967年のある日、デュポンの技術者ナサニエル・ワイエス（画家アンドリュー・ワイエスの兄）は、「なぜ炭酸のびんにプラスチックを使わないのか」と口にした。同僚は「プラスチックは弱い。炭酸でふくらんで破裂する」と答えた

{{fig:pb-wyeth-question}}

- ワイエスはプラスチックの洗剤ボトルを買い、洗剤のかわりにジンジャーエールを入れてふたをし、冷蔵庫に入れた。次の朝、ボトルはふくらんで、冷蔵庫の棚の間にがっちりはさまっていた

{{fig:pb-fridge}}

- そこで、炭酸にたえる強いプラスチックさがしを始めた。はじめはポリプロピレンで試し、のばしたときの性質がよいPETにかえた。ナイロンの糸をのばすと分子がそろって強くなることを知っていて、プリフォームを縦と横の2方向にのばす方法を考えた（[作り方](pet-bottle-making.md)）

{{fig:pb-wyeth-stretch}}

- 1970年11月に出願し、1973年5月にアメリカ特許3733309号（ワイエスとロズベア、デュポン）になった。「2方向にのばしたPETのボトル」で、約50℃で約100psi（約7気圧）までの圧力の液体を、大きく形を変えずに入れられる、と書かれている

{{fig:pb-patent}}

- PETボトルリサイクル推進協議会の年表では、1974年にアメリカで炭酸飲料に使われ始めた。アメリカの業界誌は、1977年のペプシの64オンス（約1.9リットル）のボトルを最初の飲料用PETボトルとし、底には別の部品（ベースカップ）をつけていたと書く（[花びら型の底](pet-bottle-petaloid-bottom.md)）

{{fig:pb-pepsi}}

- 同じころ、モンサントとコカ・コーラは、別の樹脂（スチレン・アクリロニトリル系）のボトルを作っていた。1977年、アメリカ食品医薬品局（FDA）がこの材料を安全でないと判断し、PETが広がる道が開いた。材料の一部が中身にうつることが問題になった

{{fig:pb-acrylonitrile}}

### 少しずつ今の形にした人たち

| 年 | 人・会社 | したこと |
|---|---|---|
| 1846年 | カイヨ（フランス） | テレビン油から酸を取り出し「テレフタル酸」と名づける |
| 1941年 | ウィンフィールドとディクソン（イギリス） | テレフタル酸とエチレングリコールでPETを作る |
| 1967〜1973年 | ワイエス（アメリカ、デュポン） | 2方向にのばしてふくらませるボトル。特許 |
| 1977年 | キッコーマン | 日本で初めて食品（しょうゆ500ml）に使う |
| 2000年 | 伊藤園 | 温めて売れるホット用（[オレンジのキャップ](pet-bottle-orange-cap.md)） |

{{fig:pb-relay}}

### 日本では、しょうゆから

| 年 | できごと |
|---|---|
| 1977年 | しょうゆの500ml容器として使い始める |
| 1982年 | 食品衛生法の改正で、清涼飲料に使えるようになる。耐熱ボトルも開発される |
| 1985年 | 焼酎の容器にも |
| 1992年 | 国の指導で「自主設計ガイドライン」を作る |
| 1993年 | 識別マークの表示が始まり、リサイクルが本格的に始まる |
| 1996年 | 小型（1リットル未満）ボトルの自主規制をやめる |
| 1997年 | 容器包装リサイクル法がPETボトルにも |
| 2001年 | 色のついたボトルをやめる（[三角のPETマーク](pet-bottle-mark.md)） |

{{fig:pb-japan-soy}}

- **なぜ小さいボトルは1996年まで出なかった？** 飲料業界は1980年代はじめにPETボトル飲料が出たときから、おもにポイ捨てで散らかるのを防ぐため、1リットル未満の小さいボトルを売るのを自分たちでひかえていた（自主規制）。容器包装リサイクル法の施行（1997年）に先立って、1996年にやめた。そのあと500mlの飲みものが一気に広まった

{{fig:pb-small-1996}}

- **ドラマと史実**：2022年のNHKの朝ドラ『ちむどんどん』で、1972年ごろの場面にペットボトル入りのしょうゆが映り、「まだない」と話題になった。しょうゆのペットボトルは1977年から。NHKは今後の参考にすると答えた

{{fig:pb-drama}}

### みてみよう

- 台所のしょうゆの容器と、飲みもののペットボトルを並べる。「どっちが先にペットボトルになった？」と予想してから、年表で確かめる（しょうゆ1977年、清涼飲料1982年）

{{fig:pb-look-history}}

- 500mlの小さいペットボトルを見たら、1996年まではなかった大きさだと思い出す。店で、びんのビールや一升びんも見つけたら、ペットボトルの前の入れものとくらべる

{{fig:pb-look-small}}

- [サントリー お客様センター「ビールびんは何年くらい使われていますか？」](https://www.suntory.co.jp/customer/faq/001707.html)：8年〜10年くらい

- [John Rex Whinfield（Wikipedia 英語版）](https://en.wikipedia.org/wiki/John_Rex_Whinfield)：1930年代後半、カロザースのナイロンに対抗する合成繊維さがし

- [Lancashire County Council「50 objects: Terylene」](https://old.lancashire.gov.uk/leisure-and-culture/museums/50-objects/item-details/?irn=1062)：1941年、アクリントンの研究室・ブロード・オーク捺染工場。戦争のため発表されず特許のみ。1946年ICIがフリートウッドに工場、デュポンが米国の権利を取得

- [PETボトルリサイクル推進協議会「PETボトルの歴史」](https://www.petbottle-rec.gr.jp/more/history.html)：1973年ワイエスが特許、1974年米国で炭酸飲料に、1977年日本でしょうゆ500ml、1982年2月食品衛生法改正、1982年耐熱ボトル、1985年焼酎、1992年自主設計ガイドライン、1993年識別マーク・リサイクル本格開始、1996年4月小型ボトルの自主規制廃止、1997年4月容リ法適用、2001年着色ボトルの廃止など

## 見るとわかること

電子レンジは、料理のために考えられた機械ではない。戦争中のレーダーを作っていた技術者のポケットで、チョコレートがとけたことから始まった。終わると鳴る「チン」は、日本の会社が自転車のベルの音から作った。

## なぜそうなっているか

### 発明した人：パーシー・スペンサー

- 1894年、アメリカのメイン州生まれ。小学5年生で学校をやめて工場で働き、16歳で製紙工場に電気を引く手伝いをしながら、ほぼ独学で電気を学んだ。海軍の無線係のときに高度な内容も自分で勉強した
- 第一次世界大戦のあと、のちのレイセオン社に入る。第二次世界大戦中、レーダーの心臓部の真空管「マグネトロン」（強いマイクロ波を出す部品）を大量に作る方法を考えた。銅のかたまりを削るかわりに、うすい金属板を型でぬいて重ね、炉でくっつける方法で、彼の部門は15人から5000人以上にふくれあがった

{{fig:magnetron-chocolate}}

### チョコ、ポップコーン、たまご

- 動いているレーダーの近くに立っていたら、ポケットのチョコレートバーがとけていた。マイクロ波で食べ物が温まるのでは、と考えた
- マグネトロンの近くにポップコーンの粒を置くと、はじけた
- やかんに入れたたまごに当てると、たまごが爆発して、同僚に飛び散った
- 食べ物を温めるには、金属の四角い箱にマイクロ波を閉じこめればよいと気づいた（マイクロ波は金属で跳ね返るので、箱の中を行き来して食べ物に当たり続ける）

### 冷蔵庫より大きかった最初の電子レンジ

| | 数字 |
|---|---|
| 特許の出願 | 1945年10月8日 |
| 発売 | 1946年「レーダーレンジ」 |
| 高さ | 約1.8m（6フィート近く） |
| 重さ | 340kg以上（750ポンド以上） |
| 値段 | 5000ドル（今のお金で約5万ドル） |

- 「レーダーのレンジ（調理台）」という名前そのもの。日本語の「電子レンジ」の「レンジ」も、英語の range（調理台、こんろ）
- 台所に置ける大きさの家庭用は、1950年代に495ドルで出た。1997年には、アメリカの家庭の90％に電子レンジがあった

### 日本の電子レンジ

| 年 | できごと |
|---|---|
| 1959年 | 東芝が業務用の国産第一号機を完成 |
| 1961年 | 東芝が市販を始める。同じ年、国際電気も業務用「DO-2273B」を発売 |
| 1960年代 | 東芝の電子レンジが、国鉄や新幹線のビュッフェ、デパートの食堂に入る |
| 1962年 | 早川電機工業（今のシャープ）が量産品「R-10」を発売。54万円 |
| 1966年 | 早川電機工業が、食べ物を回してむらなく温める**ターンテーブル**を世界で初めてつける |
| 1967年 | 早川電機工業が、終わると「チン」と鳴るしくみをつける |
| 1968年 | 東芝が、家庭のコンセントで使える出力550Wの家庭用「ER-501」を出す |

### 「チン」はなぜ生まれたか

- 「できあがったのに気づかず、料理が冷めてしまった」という苦情が来たのがきっかけ。若手社員の藤原康宏さんが、終わりの合図をつけることを思いついた
- 調理場のうるさい音の中でも聞こえる音を探していたとき、開発メンバーがサイクリング中に鳴らした**自転車のベル**がヒントになった。これが大ヒットして、家庭用にも「チン」と鳴るしくみがつけられた

## 6〜9歳むけ

でんしレンジを はつめい した ひとは、スペンサーさん。せんそうで つかう きかいを つくって いたよ。

その きかいの そばに たって いたら、ポケットの チョコが とけたんだ。きかいから でる みえない なみで、あたたまったんだよ。

{{fig:magnetron-chocolate}}

さいしょの でんしレンジは、おとなの せより たかくて、すごく おもかったんだ。

{{fig:radarange-size}}

おわると なる「チン」は、にほんの かいしゃが つくったよ。できたのに きづかないで、さめちゃう ひとが いたからなんだ。じてんしゃの ベルの おとを ヒントに したんだって。

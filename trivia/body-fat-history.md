## 見るとわかること

いまは「脂肪は燃料で、燃えると息の二酸化炭素と水になる」と知られている。でも、400年前の人は、食べたものが体の中でどうなるのか、まったく知らなかった。体重をはかり続けた医者、呼吸と火が同じだと見ぬいた化学者、ブタの脂を12年かけて分けた化学者、人を部屋に閉じこめて熱をはかった農学者。少しずつ、体の脂肪の正体がわかってきた。

## なぜそうなっているか

### なかった時代：食べたものは、どこへ消える？

- 昔の医学では、体の中のことは目に見えなかった。イタリアのパドヴァ大学で医学を教えたサントーリオ・サントーリオは、天井からつるした天びんのいすを自分で作り、30年以上、自分の体重と、食べたもの・飲んだもの、出したものの重さをはかり続けた。1614年の本に「1日に8ポンド食べたり飲んだりすると、ふつう5ポンドほどが、感じられないまま体から出ていく」と書いた。彼はこれを「感じられない発汗」とよんだ。何が出ていくのかは、まだわからなかった

{{fig:bfh-santorio}}

### 1780年代：呼吸は、ゆっくり燃えること

- フランスの化学者ラヴォアジエは、モルモットを、氷をつめた入れものの中に入れた。モルモットの体の熱で氷がとけ、とけた水の量で熱の量をはかった。世界で初めての、動物の熱をはかる熱量計。こうして、呼吸は「ゆっくり燃えること」だと示した

{{fig:bfh-ice}}

- 1789年には助手のセガンにマスクをつけさせ、吸う空気と出す二酸化炭素をはかった。何も食べずに休んでいると1時間に約24L、食べたあとは約38L、何も食べずにおもりを持ち上げる仕事をすると約63Lの酸素を使った。食べる・働く・寒さで、体の「燃え方」が変わることがわかった

{{fig:bfh-seguin}}

### 1811〜1823年：脂肪を分けると、グリセリンと脂肪酸

- その前の1779年ごろ（年は資料によってちがう）、スウェーデンのシェーレは、オリーブ油を鉛の酸化物とあたためて、あまい味の液体を取り出していた。「油のあまいもと」

{{fig:bfh-scheele}}

- フランスのシュヴルールは、1811年にブタの脂で作ったせっけんを調べはじめ、12年かけていろいろな動物の脂を調べた。脂肪はアルカリで、アルコールの一種と、脂肪酸に分かれることを示し、そのアルコールを「グリセリン」（ギリシャ語の「あまい」から）と名づけた。オレイン酸、ステアリン酸などの名前も彼がつけた。1823年に本『動物の脂肪の化学研究』にまとめ、1825年にはステアリン酸のろうそくの特許をとった。102歳まで生きた

{{fig:bfh-chevreul}}

- 1854年、フランスのベルテロは、逆にグリセリンとステアリン酸から、脂肪（トリステアリン）を作ってみせた。脂肪が「グリセリン＋脂肪酸3本」だと確かめられた（→[脂肪は何でできているか](body-fat-triglyceride.md)）

{{fig:bfh-berthelot}}

### 1819〜1897年：食べものの「カロリー」をはかる

- 熱の単位「カロリー」は、フランスの化学者クレマンが、1819年の講義ですでに定義していた（→[ことば](body-fat-words.md)）

{{fig:bfh-calorie}}

- ドイツのルブナーは、イヌが出す熱が、食べたものを燃やしたときの熱と同じになることを確かめ、1894年に「生きものの体の中でもエネルギーは消えも生まれもしない」ことをはっきりさせた

{{fig:bfh-rubner}}

- アメリカのアトウォーターは、1887年にドイツのミュンヘンでルブナーたちの研究にふれ、同じ年、食べもののカロリーという考えをアメリカに伝えた。ウェズリアン大学の物理学者ローザと、人が中に入れる大きな熱量計を作り（1892年に作りはじめ、1897年には動いていた）、脂肪・たんぱく質・炭水化物1gから体が取り出せるエネルギーの係数を決めた

{{fig:bfh-atwater}}

- その係数は、いまの日本の食品の「栄養成分表示」にも生きている。食品表示基準では、熱量は「修正アトウォーター法」で、たんぱく質4kcal/g、脂質9kcal/g、炭水化物4kcal/gをかけて足して出してよい

{{fig:bfh-label}}

### 日本：「営養」から「栄養」へ

- 愛媛の医者の家に生まれた佐伯矩（さいき ただす、1876年生まれ）は、1914年、東京の芝白金に、世界で初めての栄養学の研究所（私立栄養研究所）を作った。文部省に、「営養」とも書かれていた言葉を「栄養」にそろえるよう申し出て、この書き方が定着した。1920年に国の栄養研究所ができると初代所長になり、1924年に栄養学校を作って、卒業生を「栄養士」とよんだ

{{fig:bfh-saiki}}

### 脂肪の中身がわかってきた20〜21世紀

体の脂肪の研究を、少しずつ進めた人たちを表にするとこうなる。

| 年 | だれが | 何をした |
|---|---|---|
| 1614 | サントーリオ | 体重をはかり続け「感じられない発汗」 |
| 1780年代 | ラヴォアジエ | 呼吸はゆっくり燃えること |
| 1823 | シュヴルール | 脂肪＝グリセリン＋脂肪酸 |
| 1854 | ベルテロ | 脂肪を作ってみせる |
| 1894・1897 | ルブナー、アトウォーター | 体の中でもエネルギーは保存。人の熱量計 |
| 1914 | 佐伯矩 | 世界初の栄養の研究所 |
| 1961・1976〜78 | （多くの研究者） | 茶色い脂肪が熱を作る。UCP1 |
| 1994 | フリードマンたち | 脂肪が出す合図（レプチン）の遺伝子 |
| 2004 | ツェヒナーたち | 脂肪をほどく酵素ATGL |
| 2008 | スポルディングたち | 脂肪細胞は毎年約1割入れかわる |
| 2009 | 斉藤昌之たちほか | 大人にも茶色い脂肪 |
| 2014 | ミーアマンとブラウン | やせた脂肪の8割以上は息で出る |

{{fig:bfh-people}}

- よくある思いこみ「脂肪は燃えて熱やエネルギーになって消える」は、ラヴォアジエの「ものは消えない」と合わない。2014年にミーアマンたちが式で追いかけて、行き先が息だと示した（→[脂肪はどこへ消える？](body-fat-where-it-goes.md)）

{{fig:bfh-myth}}

### みてみよう

おかしやパンのふくろのうら、「栄養成分表示」を見てみよう。「たんぱく質」「脂質」「炭水化物」のグラム数に、4・9・4をかけて足すと、「熱量」の数字に近くなるはず。電卓で予想を確かめてみよう（食物繊維などで少しずれることもある）。130年前にアトウォーターが人の入る部屋で決めた数字が、いまも使われている。

{{fig:bfh-look}}

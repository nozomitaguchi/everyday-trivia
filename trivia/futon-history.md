## 見るとわかること

綿の入ったふとんを掛けて寝るのは、日本では新しい習慣。昔の人びとは、むしろやござを敷き、昼間に着ていた着物をかけて寝た。室町時代に**木綿**がやってきて寝具に「一大革命」がおき、桃山時代に綿の入った大きな着物の形の「**夜着（よぎ）**」が生まれ、江戸時代の中ごろに関西で四角い掛けぶとんが作られた。それでも綿のふとんは高く、どこの家にもあるようになったのは大正の終わりから昭和にかけて。羽毛ふとんの工場は1954年、ふとん乾燥機は1977年から。

## なぜそうなっているか

### ふとんがなかったころ

- 庶民は「下着のままか、裸のままで寝て、上には昼間着ていた上着をかけていた」。庶民の家には畳もなかった（日本大百科全書）

{{fig:ft-old-commoner}}

- いちばん古い敷くものは**薦（こも）**と**筵（むしろ）**。材料はわらが多く、イグサ、ガマ、竹も使われた（世界大百科事典、日本大百科全書）

{{fig:ft-mushiro}}

- 掛けるものは**衾（ふすま）**とよばれ、今の掛けぶとんにあたる。麻の衾、紙の衾などがあった（日本国語大辞典）。上流の人びとは、床板の上に畳を敷き、衾をかけて寝た（山川日本史小辞典）

{{fig:ft-fusuma}}

- 平安時代の貴族は、床の上に畳を2つならべ、その上に**御帳（みちょう）**を立てて寝所にした。御帳は、四方を布でかこった台。そのころの畳は、今の畳とはちがい、薦や筵のようなものだった（日本大百科全書）

{{fig:ft-heian}}

- 和紙で作った**紙衾（かみぶすま）**は、軽く、あたたかく、安く、じょうぶで、民間で多く使われた。産地は仙台と駿河の安倍川。江戸では「天徳寺（てんとくじ）」とよばれ、江戸時代の中ごろまで売り歩く人がいた（日本大百科全書）

{{fig:ft-kamibusuma}}

### 木綿がやってきた

| 年 | できごと |
|---|---|
| 799年 | 三河に流れ着いた人が綿の種を持ってきたが、根づかなかった |
| 1400年代 | 朝鮮から木綿が入る（日朝貿易で朝鮮からもらう大事な品） |
| 1510年 | 奈良の記録に「三河木綿」の名が出る |
| 1500年代 | 国内で綿の栽培がすすむ |

{{fig:ft-cotton-arrives}}

### 少しずつ今の形にした人たち

| 時代・年 | だれが・どこで | 何が変わったか |
|---|---|---|
| 室町時代 | 木綿を手にした人びと | 寝具の「一大革命」。呼び名も、敷く上蓆（うわむしろ）が「蒲団」に、衾が「夜着」に。ただ、木綿の寝具は大変な貴重品 |
| 桃山時代 | — | 大きな着物の形の、綿を入れた「夜着」が登場 |
| 元禄（1688〜1704年）ごろ | — | 側も中身も木綿の寝具が広まりはじめる。夜着を小さくした「搔巻（かいまき）」 |
| 江戸時代の中ごろ以降 | 関西 | 四角い掛けぶとん「大蒲団」が作られ、夜着はしだいに消える。関東から東北では搔巻が近年まで使われた |
| 明治 | 一部の上の階級の人 | ベッドを使いはじめる |
| 大正の終わり〜昭和 | 全国 | 綿の入ったふとんが本当に広まる。それまで多くの農村では、薦・筵・わら |
| 1954年 | 東洋羽毛工業（神奈川県相模原市） | 日本初の羽毛寝具の量産工場 |
| 1977年 | 三菱電機 群馬製作所 | 国産初のふとん乾燥機 AD-600形 |

{{fig:ft-futon-steps}}

- 江戸時代でも、綿の入った夜具は「庶民にとっては高価でまだ手に入れることが難しく、多くは嫁入り支度など特別なときに誂える品」だった（国際基督教大学 湯浅八郎記念館）

{{fig:ft-yomeiri}}

- 夜着は、えりとそでのある着物の形をしていた。幕末になると、えりもそでもない長方形の夜着が生まれた（世界大百科事典）。着物の形から、今の四角い形へ。そでやえりのある掛けものは、今も「搔巻」とよばれている（ジャパンナレッジ）

{{fig:ft-yogi-shape}}

### 羽毛のふとんと、羽毛をくれる鳥

- アイスランドでは、ケワタガモ（アイダー）のメスが、巣をつくるとき自分の胸の羽毛（ダウン）をぬいて卵の下にしく。アイスランドの人は、9世紀に島に住みはじめたころからケワタガモといっしょに暮らし、1847年に完全な保護鳥にした。鳥にとって安全なときに、農家が巣から羽毛を集める

{{fig:ft-eider}}

- 日本の羽毛ふとんは、1954年8月10日、相模原市に東洋羽毛工業ができ、日本初の羽毛寝具の量産工場として始まった。8月10日は「羽毛ふとんの日」。日本羽毛製品協同組合のまとめでは、国内の羽毛ふとんの生産は2009年の176万枚がいちばん多かった

{{fig:ft-down-japan}}

### ふとん乾燥機

- 1977年、三菱電機群馬製作所が、国産第1号のふとん乾燥機 AD-600形を発売した。はじめは北陸地方でためしに売り、そのあと都会の高層マンションに住む人にも広がった（国立科学博物館 産業技術史資料データベース）

{{fig:ft-dryer-1977}}

### みてみよう

- 「搔巻（かいまき）」や、そでのついた毛布を売り場や家で見かけたら、**えりとそで**を見る。四角い掛けぶとんとくらべて、どこが着物の形のなごりか、見る前に予想する。売り場で見つからなければ、博物館や絵の中の夜着の形をさがす

{{fig:ft-look-kaimaki}}

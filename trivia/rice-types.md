## 見るとわかること

ふだん炊くお米は「うるち米」、おもちやお赤飯にするのは「もち米」。もち米は、炊くとよくのびてねばる。世界には、細長くて炊くとパラパラになるお米もある。ちがいは、粒の中のでんぷんの「つながり方」と、イネの種類から来ている。

## なぜそうなっているか

### でんぷんには2つの形がある

- **アミロース**：ブドウ糖がまっすぐ長いくさりのようにつながったもの

{{fig:rice-amylose}}

- **アミロペクチン**：くさりのとちゅうから枝分かれして、木の枝のように広がったもの。ほとんどがアミロペクチンのもち米は、うるち米よりねばりが強い

{{fig:rice-amylopectin}}

### うるち米ともち米

| | うるち米 | もち米 |
|---|---|---|
| でんぷん | アミロペクチン約8割、アミロース約2割（日本のうるち米） | ほとんどがアミロペクチン |
| ねばり | もち米より少なめ | 強い |
| 冷めると | かたくなりやすい | かたくなりにくい |
| 使いみち | ふだんのごはん | おもち、お赤飯 |

{{fig:rice-starch-ratio}}

{{fig:rice-uruchi-mochi}}

- 冷めたごはんがかたくなるのは、ほぐれたでんぷんから水がぬけて、またぎゅっとつまるから。アミロースはこれが早く、アミロペクチンはゆっくり。だから、ほとんどアミロペクチンのもち米は冷めてもかたくなりにくい（→[ごはんはなぜふっくら炊けるのか](rice-cooking.md)）

{{fig:rice-cool-hard}}

### ジャポニカとインディカ

アジアのイネは、大きく2つの仲間に分けられる。

| | ジャポニカ | インディカ |
|---|---|---|
| 形 | 短くて丸い | 細長い |
| 炊くと | ねばりとつやが出る | パサパサする |
| 寒さ | 比較的強い | — |
| おもな産地 | 日本、朝鮮半島、中国東北部、アメリカのカリフォルニアなど | インド、中国南部、東南アジアなど。世界でいちばん多く作られている |

{{fig:rice-japonica-areas}}

{{fig:rice-japonica-indica}}

- 世界のお米（もみ）は1年に約7億8729万トン作られ、中国・インド・バングラデシュの3か国で約6割。日本は1,053万トンで12位

{{fig:rice-world}}

### けずり方の違い（精米の度合い）

| 名前 | 玄米の重さのうち残る分 | けずり方 |
|---|---|---|
| 玄米 | 100% | もみがらを取っただけ |
| 半つき米・七分つき米 | 95〜96%・93〜94% | ぬかを少し残す |
| 白米（精白米） | 90〜92% | ぬか層と胚芽を取る。胚芽を8割以上残すと「胚芽精米」 |

{{fig:rice-polish-degree}}

- お酒用のお米（酒米）は大粒の品種を使い、味をじゃまする成分が外側に多いので、ごはん用よりずっと大きくけずる

{{fig:rice-sake-polish}}

- 赤米はぬかに赤い色素、紫黒米（しこくまい）はぬかに紫の色素をもつ。色がついているのはぬか層なので、けずると白くなる

{{fig:rice-colored}}

## 3〜5歳むけ

いつもの ごはんの おこめと、おもちの おこめが あるよ。

{{fig:rice-uruchi-mochi}}

おもちの おこめは、びよーんと よく のびるんだ。

つめたく なっても、やわらかいよ。

{{fig:rice-cool-hard}}

ほそながい おこめの くにも あるよ。

{{fig:rice-japonica-indica}}

おみせで、ちがう おこめを さがして みてね。

## 6〜9歳むけ

おこめの なかの でんぷんには、2つの かたちが あるよ。まっすぐな くさりと、えだわかれした くさりだよ。

{{fig:rice-amylose}}

えだわかれした ほうが おおいと、よく ねばるんだ。

{{fig:rice-amylopectin}}

おもちの おこめは、ほとんどが えだわかれの ほう。だから びよーんと のびるよ。

{{fig:rice-uruchi-mochi}}

なぜ つめたい ごはんは かたいのかな。まっすぐな くさりが、すぐ ぎゅっと くっつきなおすからだよ。

{{fig:rice-cool-hard}}

インドなどでは、ほそながくて パラパラの おこめを たべるよ。

{{fig:rice-japonica-indica}}

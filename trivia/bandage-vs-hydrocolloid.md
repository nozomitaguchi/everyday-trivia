## 見るとわかること

ガーゼのない、はると白くふくらむばんそうこう（キズパワーパッドなど）は、**ハイドロコロイド**という材料でできている。水を吸う小さなつぶが、傷から出る体液を吸ってゼリーのようにふくらみ、傷をしめらせたまま守る。白いのは膿（うみ）ではなく、体液を吸ったゲル。法律では、ふつうのばんそうこうより一段上の「管理医療機器」で、深い傷・かまれた傷・ばい菌が入った傷などには使ってはいけない。2歳以下の子にも使わない。

## なぜそうなっているか

### 2つのなかまをくらべる

| | ふつうのばんそうこう | ハイドロコロイド |
|---|---|---|
| 傷に当たる所 | ガーゼのパッド | 全体がハイドロコロイド |
| 法律の名前 | 一般医療機器「救急絆創膏」 | 管理医療機器「家庭用創傷パッド」 |
| 水 | ぬれたらすぐ貼り替える | 表面が防水フィルム |
| 替えどき | ぬれた・よごれた | 白いふくらみがはしまで来た |

{{fig:bd-y-compare}}

- ふつうのばんそうこうは、傷をおおって守るのが目的で、パッドがぬれたらすぐ貼り替える（[ばんそうこうとは何か](bandage-basics.md)）

{{fig:bandage-dry}}

- キズパワーパッドは、書類の名前が「管理医療機器 家庭用創傷パッド」（医療機器認証番号 225ADBZI00048000）。池田模範堂のハイドロコロイドパッドも同じ「家庭用創傷パッド（JMDNコード 71025000）」。ふつうのばんそうこうの「一般医療機器」より、リスクの区分が一段上

{{fig:bd-y-class}}

### なぜ白くふくらむのか

- キズパワーパッドは「二層構造。外側は、バイ菌や水の侵入を防ぐポリウレタンフィルム。内側は、ハイドロコロイド素材」（バンドエイド公式）

{{fig:bd-y-two-layers}}

- ハイドロコロイドは、皮ふにくっつく粘着剤（水をはじく「疎水性ポリマー」）の中に、水を吸う「ハイドロコロイド粒子（親水性ポリマー）」をまぜたもの（同）

{{fig:bd-y-particles}}

- 「このハイドロコロイド粒子が、キズ口に出てくる体液を吸収してふくらみ、ゼリーのようなゲル状のクッションになります」（同）。池田模範堂の書類も「体液（滲出液）を吸収し、その部分がゲル状に白くふくらみ」と書く

{{fig:hydrocolloid-swell}}

- 傷がなおって体液が少なくなると、ふくらみ方も小さくなる（バンドエイド公式）。ふくらまないときは、傷に合っていないか、ほとんどなおっているかのどちらか

{{fig:bd-y-less-swell}}

### 白いのは膿？ 見分け方

| | 体液 | 膿（うみ） |
|---|---|---|
| 色 | 透明でうすい黄色 | 淡い黄色 |
| さわった感じ | サラサラ | ねばねば |
| におい | ない | ある |
| 出るころ | 傷ができて数時間〜1日 | 傷ができて3、4日後 |
| いたみ | ない | ズキズキが続く |

{{fig:bd-y-pus}}

- バンドエイド公式のQ&Aの表。「『膿かな？』と思ったら医師に相談をしましょう」。感染の症状があれば、すぐ使うのをやめて医師に相談する

{{fig:bd-y-doctor}}

### しめらせると、なぜよいのか

- 1962年、イギリスのジョージ・ウィンターは、子ブタの浅い傷で、かさぶたができないようにすると新しい皮ふの広がりがずっと速くなることを示した（[かさぶたの歴史](scab-history.md)、[かさぶたを作らない治し方](scab-moist.md)）

{{fig:bd-y-winter}}

- バンドエイド公式は、しめらせると、皮ふを作り直すのにいる体液が傷の上にとどまり、神経が乾いた刺激から守られるので痛みもやわらぐ、と説明している

{{fig:hydrocolloid-origin}}

### どこから来た材料か

- ハイドロコロイドの医療用粘着剤は、1960年代にアメリカのスクイブ社のジェームズ・チェン博士が、何百もの配合をためして作った（コンバテック社の歴史）

{{fig:bd-y-chen}}

- その最初の製品は、ストーマ（おなかに作った便や尿の出口）のまわりの皮ふを守る「ストーマヘシブ」。1978年にコンバテック社ができたあとに売り出された（同）

{{fig:bd-y-stoma}}

- 日本では2004年に、キズパワーパッドが「家庭向け製品でモイストヒーリングを採用した」初めての製品として出た（ジョンソン・エンド・ジョンソン）。作っているのはデンマークのコロプラスト社（外国特例認証取得者）

{{fig:bd-y-2004}}

### 使ってはいけない傷・人

- 使ってはいけない：深い刺し傷、筋肉や骨が見えるような深い傷、かさぶたができている傷、動物や人にかまれた傷、異物が入った傷、原因のわからない傷（バンドエイド公式Q&A）

{{fig:bd-y-not-for}}

- にきび・湿疹・虫さされ・皮ふ炎や、それをかきこわした傷にも使わない。目のまわりや粘膜（口の中など）もさける

{{fig:bd-y-not-skin}}

- やけどは軽いものだけ。池田模範堂の書類は、「出血を伴うやけど、患部が白や黒に変色して感覚がない重度のやけどの可能性がある傷」には使わないとしている

{{fig:bd-y-burn}}

- 「2歳以下の乳幼児には使用しないでください」。3歳以上は「必ず保護者の監督のもと」で使う（バンドエイド公式）

{{fig:bd-y-age}}

### 使い方と、切ってはいけないわけ

1. 水道の流水で「異物やバイ菌をしっかり洗い流します」。消毒液やクリームはぬらない

{{fig:bd-y-wash}}

2. 血が出ていたら止める。2〜3分たっても止まらなければ病院へ

{{fig:bd-y-stop}}

3. ぴったり貼って、傷のうるおいを保つ

{{fig:bd-y-apply}}

4. 傷のようすを見る。白いふくらみがはしまで来たら、はしがはがれたら、貼り替える

{{fig:bd-y-watch}}

- 切ると「切断面はハイドロコロイド素材がむき出しになってしまい、防水・防菌の性能を十分に発揮できません」。だから切らずに1枚ずつ使う

{{fig:hydrocolloid-nocut}}

- 表面は完全防水なので、シャワーや水仕事でも貼ったままでいられる（バンドエイド公式）

{{fig:hydrocolloid-waterproof}}

### みてみよう

- 救急箱にふつうのばんそうこうとハイドロコロイドのものがあれば、箱の小さな字をくらべる。「一般医療機器」と「管理医療機器」、どちらがどちらか予想してから確かめる。箱の「使用上の注意」に、使えない傷や年れいが書いてあるかもさがす

{{fig:bd-look-hydro-2}}

- ハイドロコロイドを使っているときは、白いふくらみがはしまで来ていないか、上から見るだけで確かめる（はがして中を見ない）

{{fig:bd-look-hydro}}

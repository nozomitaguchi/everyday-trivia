## 見るとわかること

ポリエチレンは、だれかが「袋の材料を作ろう」とねらって作ったものではない。別の実験の失敗のようなところから何度も偶然見つかり、戦争で役に立ち、そのあと「触媒」の発明でだれでも安く作れるようになって、袋になった。

## なぜそうなっているか

### 3回の「偶然」

| 年 | だれが | なにが起きたか |
|---|---|---|
| 1898年 | ハンス・フォン・ペヒマン（ドイツ） | ジアゾメタンという物質を調べていて、白いろうのような固まりが偶然できた |
| 1900年 | バンベルガーとチルナー | その固まりが –CH₂– の長いくさりだと調べ、「ポリメチレン」と名づけた |
| 1930年 | マーベル（アメリカ） | 別の実験でポリエチレンらしきものができたが、それ以上追いかけなかった |
| 1933年 | フォーセットとギブソン（イギリスICI社） | エチレンとベンズアルデヒドを約1400気圧で反応させる実験で、白いろうのような固体が容器に残った |

- 1933年の固体は、同じ条件で何度やってもできたりできなかったりした。原因を追うと、装置にほんの少しまじっていた**酸素**が反応のきっかけ（ラジカル）になっていたとわかった。偶然まじっていた酸素がなければ、見つからなかった

{{fig:oxygen-accident}}
- 1935年、同じICI社のマイケル・ペリンが、酸素の量をコントロールしてくり返し作れる高圧法にまとめた
- 1939年、低密度ポリエチレンの工業生産が始まった

### 戦争で「秘密の材料」に

- ポリエチレンは電気をほとんど通さず、高い周波数の電気信号を弱めにくい。この性質が、第二次世界大戦中のレーダーの同軸ケーブルの絶縁にぴったりだった
- イギリスでは一般への販売が止められ、軍事用になった。1944年にはアメリカのデュポン社とユニオンカーバイド社がICI社の許可を得て大量生産を始めた

### 「すごい圧力」をいらなくした触媒

高圧法は1000〜2000気圧以上の大がかりな装置が必要だった。これを変えたのが**触媒**（反応を手伝う物質）。

{{fig:pressure-compare}}

| 年 | だれが | 発明 |
|---|---|---|
| 1951年 | ホーガンとバンクス（アメリカ フィリップス社） | 酸化クロムの触媒。おだやかな温度と圧力でつながる |
| 1953年 | カール・ツィーグラー（ドイツ） | 塩化チタンと有機アルミニウムの触媒。もっとおだやかな条件（10気圧以下、60〜80℃）でつながる |
| 1963年 | ツィーグラーとナッタ | ノーベル化学賞 |
| 1968年〜 | | 気相法。ガスのまま触媒の粒にふきつけてつなぐ |
| 1970年代 | | ツィーグラー触媒に塩化マグネシウムが加えられる |
| 1976年 | カミンスキーとジン（ドイツ） | 溶ける触媒「メタロセン触媒」を報告 |

- 触媒の表面ではエチレンが1個ずつ順番につながるので、枝の少ないまっすぐなくさり＝**高密度ポリエチレン**ができる。高圧法では作れなかった、かたくて丈夫なポリエチレンが生まれた
- 1960年代には高密度ポリエチレンのボトルが登場し、多くの用途でガラスびんに取って代わった

### うすくて破れにくい袋へ（直鎖状低密度）

- まっすぐなくさりにわざと短い枝をつける**直鎖状低密度ポリエチレン**は、1960年にデュポン・カナダ社が最初の商業ラインを作った
- 1979年、ユニオンカーバイド社が気相法（ユニポール法）で本格的に売り出した。反応の圧力は約7〜20気圧（100〜300psi）で、高圧法の約2000〜3400気圧（3万〜5万psi）の100分の1ほど。工場を安く作れるようになった
- いちばん伸びた用途は袋やフィルム。1980年代の終わりには、直鎖状低密度ポリエチレンの使われ方の75％がフィルムになった

### いま

- 2017年の時点で、ポリエチレンは世界で年に1億トン以上作られ、プラスチック全体の約34％をしめる。いちばんたくさん作られているプラスチック

## 6〜9歳むけ

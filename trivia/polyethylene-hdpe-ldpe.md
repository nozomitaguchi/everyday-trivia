## 見るとわかること

同じポリエチレンの袋でも、レジ袋はシャカシャカ音がして白っぽく、ゴミ袋や保存袋はしっとりやわらかく透明に近い。ちがいは材料ではなく、ポリエチレンの**くさりの枝分かれ**のしかた。

## なぜそうなっているか

- ポリエチレンのくさりには、ところどころ「枝」が出ている。枝が少ないくさりは、きちんと折りたたまれてすき間なく並ぶ（**結晶**になる）。枝が多いと、からまってすき間だらけになる

{{fig:pbag-branch-pack}}

- きちんと並んだ部分（結晶）は密度が約1.0 g/cm³、からまった部分は約0.86 g/cm³。結晶が多いほど全体が重く（高密度に）なる

{{fig:pbag-density-scale}}

- 結晶の部分は光を散らすので、結晶が多いほど白っぽく半透明になる。かたいので、こすれるとシャカシャカ鳴る

{{fig:pe-crystal-light}}

| | 高密度（HDPE） | 低密度（LDPE） |
|---|---|---|
| 枝 | ほとんどない | 長い枝がたくさん |
| 結晶の割合 | 約80％ | 約35％ |
| 密度（g/cm³） | 0.93より大きい | 0.91〜0.93 |
| とける温度 | 120〜130℃ | 105〜115℃ |
| さわると | シャカシャカ・かため | しっとり・よく伸びる |
| おもな袋 | レジ袋 | ゴミ袋、チャック付き袋 |

{{fig:pbag-hd-ld-table}}

3つ目の**直鎖状低密度（LLDPE）**は、密度0.916〜0.940、結晶の割合は低密度と同じ約35％。ちがうのは枝の形で、短い枝がまっすぐなくさりにそろって付いている。うすくても破れにくく、アメリカではゴミ袋と、荷物を巻きつけて固定するストレッチフィルムが二大用途。日本の45リットルのゴミ袋も、直鎖状低密度で0.02〜0.03mmの厚さのものがある。

### 枝はどうしてできるのか

- **低密度**：2400気圧の高圧法では、つながる反応があばれるように進み、くさりの途中から別のくさりが生えてくる。これが長い枝になる

{{fig:pbag-long-branch}}

- **高密度**：触媒の表面で1個ずつ順番にエチレンをつなぐので、まっすぐなくさりになる

{{fig:pbag-straight-chain}}

- **直鎖状低密度**：高密度と同じまっすぐなつなぎ方の途中に、ブテン・ヘキセン・オクテンという少し長い分子を1〜10％まぜる。まぜた分子が短い枝になって、わざと結晶をじゃまする。長い枝がないのでくさりどうしがからみにくく、引っぱるとすべるように伸びるので、うすくしても破れにくい

{{fig:pbag-short-branch}}

### しっとりした袋ほど、口が開きにくい

スーパーの台にあるロールの袋や、ゴミ袋の口が、こすってもなかなか開かないことがある。重なったフィルムどうしがくっついてはがれにくくなることを**ブロッキング**という。

- フィルムの表面がなめらかなほど、くっつきやすい

{{fig:pbag-block-smooth}}

- 密度が低い（結晶が少ない）ほど、くっつきやすい。しっとりした低密度の袋のほうが開きにくい

{{fig:pbag-block-density}}

- うすいほど、くっつきやすい。運ぶときや倉庫で熱や重さがかかっても起きる

{{fig:pbag-block-thin}}

- そこでメーカーは、ごく小さな粒をまぜた添加剤を樹脂に練りこみ、表面に目に見えない小さなでこぼこを作って、ふれあう面積を減らしている（アンチブロッキング剤）。粒には、シリカ（二酸化ケイ素）やタルクという石の粉が使われる

{{fig:pbag-antiblock}}

### 見分け方の目安

- シャカシャカ音がして、白っぽく半透明 → 高密度

{{fig:bag-feel-test}}

- 音がせず、しっとり透明で、指で押すとよく伸びる → 低密度・直鎖状低密度

{{fig:pbag-feel-soft}}

- ただし、色や添加剤、厚さでも見た目は変わる。見た目だけで材料を決めつけない

{{fig:pbag-not-sure}}

### みてみよう

- レジ袋とゴミ袋（または台所のチャック付き袋）を並べて、向こう側の景色の見え方をくらべる。白っぽくかすむのはどちらか、予想してから見る

{{fig:pbag-look-haze}}

- スーパーの台のロールの袋は、レジ袋より透明でしっとりしている。開きにくいのはどちらの袋か、まわりの人が袋を開けるところを見てくらべる

{{fig:pbag-look-roll}}

## 6〜9歳むけ

おみせの ふくろも ゴミぶくろも、おなじ「ポリエチレン」で できて いるよ。

{{fig:pbag-two-kinds}}

ちがいは、くさりの ならびかた。くさりに「えだ」が すくないと、きちんと たたまれて ならぶよ。

{{fig:pbag-branch-pack}}

きちんと ならぶと、かたくて シャカシャカ なるんだ。ひかりが ちらばって、しろっぽく みえるよ。

{{fig:pe-crystal-light}}

えだが おおいと、くさりが からまって すきまが できるよ。だから、やわらかくて しっとり するんだ。

{{fig:pbag-long-branch}}

しっとりした ふくろは、くちが ひらきにくいよ。つるつるの めんどうしが、ぴたっと くっつくからなんだ。

{{fig:pbag-block-smooth}}

レジぶくろと ゴミぶくろを ならべて、むこうの けしきを みて みよう。しろっぽく かすむのは どっちかな。

{{fig:pbag-look-haze}}

## 見るとわかること

緑の四角の中を、白い人がドアに向かって走っている非常口のマーク。これは1970年代の終わりに日本で全国から案を集めて作られ、1982年に日本で採用されたあと、ソ連（いまのロシアなど）の案と競って、1987年に国際標準（ISO）になった。

## なぜそうなっているか

### マークがなかった時代は「字」だった

- 日本照明工業会の会報に「誘導灯の歴史」を書いた神忠久は、1960年代なかごろ、いなかの映画館で**赤い地に白抜きで「非常口」と書いた**誘導灯を見たと書いている。中は約10Wの白熱電球だった

{{fig:exit-old-red}}

- 1975年ごろまでの標準の誘導灯は、**緑の地に白抜きで「非常口」**などの字。大きさは縦12cm・幅36cmで、10Wの蛍光ランプが入っていた

{{fig:exit-kanji-vs-pictogram}}

- 字には弱点があった。実験では、「非」「常」の字は**ごく薄い煙の中でも見えなくなった**。それに、子どもや外国の人には「非常口」の字の意味がわからない

{{fig:exit-smoke-kanji}}

### 大きな火事のあとで

- 1972年の大阪・千日デパートビル火災（死者118人）と、1973年の熊本・大洋デパート火災（死者103人）をきっかけに、1974年に消防の決まりが変わった。小さな誘導灯に加えて、縦20cm・幅60cmの中形と、縦40cm・幅120cmの大形ができ、広い建物ほど大形を付けることになった

{{fig:exit-1974-sizes}}

- 「漢字が読めなかったせいで亡くなった人がふえた」と書く記事もあるが、それを確かめた公式の資料は見つからない。記録に残っている理由は、上の「煙で字が消える」「子どもや外国の人にわからない」の2つ

{{fig:exit-myth-check}}

### 3337点の案から、科学的に選ぶ

- 1978年、日本消防設備安全センターの「防災システム研究委員会」が、誘導灯の絵のマークを全国から募集し、**3337点**が集まった（神忠久の記録）。デザイナーの太田幸夫は「79年、消防庁は非常口サインのアイデアを一般に募集」と書いていて、年と主催の書き方が資料によってちがう

{{fig:exit-contest}}

- いちばんよい案を「科学的に選ぶ」ため、5種類のテストをした。①図形の粗さ ②デザイン ③心理的な印象 ④ふつうの明かりでの見え方 ⑤**煙の中での見え方**

{{fig:exit-five-tests}}

- 選ばれた案をもとに、太田幸夫が58点のデザイン案を作り、そこから1点を選んだ。「中から外へ向かう動き」が一目で伝わるようにしたという。走る人の足先に影をつける条件がついたが、そのままでは左の壁の影と近すぎたため、体全体を少しずつ直して今の形になった

{{fig:exit-58-drafts}}

- 1982年1月、このマークが消防庁に採用された

{{fig:exit-design-parts}}

### ソ連の案との競争

| 年 | できごと |
|---|---|
| 1980年5月 | 日本の案をISO（国際標準化機構）に提案。ISOでは、数年かけてソ連の案に決まりかけていた |
| そのあと | ソ連が日本政府に抗議文を送る。太田幸夫がデザインの立場から反論した |
| 1982年4月 | ロンドンの会議で、ソ連が自分の案を取り下げる |
| 1983年3月 | ノルウェーの会議で、フランスとイギリスが一部を直す案を出す |
| 1984年12月 | パリの最後の作業部会で、全員の拍手で日本の案が正式なISOの案に |
| 1987年8月 | ISO 6309（火災の安全標識）として発行 |
| 2003年 | 安全標識をまとめた ISO 7010 で、E001（左向き）・E002（右向き）の非常口の記号に |

{{fig:exit-iso-race}}

### 少しずつ今の形にした人たち

| だれが | いつ | 何をした |
|---|---|---|
| 勝見勝（デザイン評論家）たち | 1964年 | 東京オリンピックで、国際行事の案内を絵文字でそろえた。太田は自分の仕事をこの流れで語っているが、非常口の形に直接えいきょうしたと書いた資料は見つからない |
| 太田幸夫 | 1964年〜 | イタリア留学中から、絵で通じあう文字「LoCoS（ロコス）」を研究 |
| 防災システム研究委員会 | 1978年〜 | 全国から案を集め、煙の中の見え方などで選ぶ |
| 入選した案の作者 | 1978〜79年 | 走る人のもとの案（名前は確かめられた資料がない） |
| 太田幸夫 | 1979年〜 | 58点の案から形をととのえ、ISOでソ連の案に反論 |
| 消防庁 | 1982年 | 日本の誘導灯のマークとして採用 |
| ISO（TC 21） | 1987年 | 世界の標準に |

### アメリカは「EXIT」の字から

- アメリカでは、1911年のトライアングル・シャツウエスト工場の火事で、出口がわかりやすく示されていなかったことが問題になった。全米防火協会（NFPA）は1913年に「人命安全委員会」を作り、1927年に出口についての最初の決まり（Building Exits Code）を出した

{{fig:exit-us-1911}}

- アメリカでは長く「EXIT」の字のサインが基本で、色は決まっていない（NFPAが求めるのは字と地の見やすさ）。2016年版のサインの安全規格（UL 924）から走る人の記号のサインもはっきり認められ、建物の基準（IBC）も2021年版でそれを取り入れた。ただ、職場の安全の決まり（OSHA）は今も「Exit」の字を求めていて、走る人の記号は「加えて付けてよい」という扱い

{{fig:exit-world}}

{{fig:emergency-exit-history}}

### みてみよう

- 走る人は、いつもドアのある方を向いている。左向きと右向きの両方をさがして、「矢印があるなら、人も同じ向きに走っているはず」と予想してから確かめる（見るだけ）

## 見るとわかること

ケチャップは、最初はトマトではなく**魚**を塩づけにした汁の名前だった。イギリスでキノコやクルミのソースになり、アメリカでトマトのソースになった。ところがトマトのケチャップはくさりやすく、薬（保存料）をたくさん入れて売られていた。1900年代のはじめ、ハインツは熟したトマトと、たっぷりの酢・砂糖・塩で、薬なしでも長もちするケチャップにした。今のケチャップのあまずっぱさは、そのなごり。日本では、だれも買ってくれなかったトマトを何とか使おうとして生まれた。

## なぜそうなっているか

### ケチャップがなかったころ：冷蔵庫も缶詰もない時代の「長もちソース」

- 中国南部の福建あたりのことば（閩南語）で、魚や貝を塩づけにした汁を「コエチャップ（kôe-chiap）」などとよんだ。発酵させた魚のソースは、くさらずに何か月ももった

{{fig:kc-fish-brine}}

- 1600年代の終わり、イギリスの船乗りや商人がこれをアジアで知り、国に持ち帰った。英語の本に「ケチャップ」の字が出てくるいちばん古い例は1682年（→[ことば](ketchup-words.md)）

{{fig:kc-ship}}

- 高い輸入品のかわりに、イギリスでは身近な材料でまねをした。1747年のハナ・グラスの料理の本には、キノコを塩づけにして9日おき、出てきた汁にビール・アンチョビ（小魚）・香辛料を入れて半分まで煮つめる「イングリッシュ・ケチャップ」がのっている。同じ人の別の本には「20年もつケチャップ」もあり、「インドまで持っていける」と書いた

{{fig:kc-mushroom-ketchup}}

### 魚 → キノコ → トマト

| 時代 | 場所 | どんなケチャップ |
|---|---|---|
| 1600年代まで | 中国南部・東南アジア | 魚や貝を塩づけにした汁 |
| 1700年代 | イギリス | アンチョビ、キノコ、クルミで作る、うすい茶色のソース |
| 1800年代 | アメリカ | トマトのケチャップが広まる |

{{fig:ketchup-fish-to-tomato}}

### 少しずつ今の形にした人たち

| 年 | だれが・どこで | 何をしたか |
|---|---|---|
| 1727年（初版） | エライザ・スミス（イギリス） | 大人気の料理の本『ザ・コンプリート・ハウスワイフ』に、アンチョビ・エシャロット・酢・しょうが・ナツメグのケチャップをのせる |
| 1747年 | ハナ・グラス（イギリス） | キノコのケチャップのレシピ |
| 1812年 | ジェームズ・ミーズ（フィラデルフィアの医師） | トマトを「ラブアップル（愛のりんご）」とよび、1本ごとにブランデーを入れる「ラブアップル・ケチャップ」をのせる。アメリカでいちばん早いトマトのケチャップのレシピの1つ |
| 1824年 | メアリー・ランドルフ（ヴァージニア） | 料理の本『ヴァージニアの主婦』に「トマタ・キャッツアップ」。トマト・塩・たまねぎ・メース・こしょうで、砂糖は入らない |
| 1876年 | F&Jハインツ社（アメリカ、ペンシルベニア州） | トマトケチャップを「キャッツアップ」の名で売り出す |
| 1906年ごろ | ハインツ社 | 保存料を使わないケチャップを完成させる |
| 1908年 | 蟹江一太郎（愛知県） | 日本でトマトケチャップを作り始める（今のカゴメ） |

{{fig:kc-people}}

### トマトのケチャップは、すっぱくなって、ときどき破裂した

- 魚やキノコのうすいソースとちがい、トマトのケチャップは長もちしなかった（スミソニアン誌）

{{fig:kc-tomato-spoil}}

- 1800年代のアメリカ人があまい味を好んで砂糖を入れるようになると、砂糖が発酵を早め、ケチャップはすっぱくなり、ときには**破裂**した（食べものの歴史家アンドリュー・F・スミスの説明）。1895年の新聞には「ケチャップのびんが、夕食のテーブルの上で破裂した」という記事がある

{{fig:kc-explode}}

- 1909年のアメリカ食品医薬品局（FDA）の記録では、多くの会社が、缶詰工場で出たトマトの芯や皮を発酵させてケチャップを作り、酢と、赤くするための色素を入れ、「破裂しやすい」ので安息香酸ナトリウム（保存料）を足していた

{{fig:kc-scraps}}

### ハインツは、なぜ「保存料なし」にこだわったか

- ヘンリー・J・ハインツは1869年、母のレシピの西洋わさび（ホースラディッシュ）を、当時ふつうだった茶色のびんではなく**とうめいなびん**に入れて売った。中身がきれいなことを見せるため

{{fig:kc-clear-glass}}

- その会社は1875年に破産。1876年、弟といとこと新しい会社を作り、トマトケチャップを売り出した。ハインツも、はじめは木の皮からとったサリチル酸、のちに安息香酸ナトリウムを保存料に使っていた

{{fig:kc-heinz-1876}}

- アメリカ農務省の化学者ハーヴェイ・ワイリーは、保存料などの食品添加物を、ボランティアの人に食べてもらって調べる実験（「毒味部隊」とよばれた）を1902年に始め、安息香酸ナトリウムを危ないと考えた。1906年6月、「純正食品・薬品法」が、食肉検査法とともにできる。アメリカで、消費者を守る大きな法律の最初の2つだった。ハインツは、この法律に賛成した数少ない食品会社だった

{{fig:kc-wiley}}

- ハインツはいとこで工場長のセバスチャン・ミューラーに、薬を入れなくてもよいケチャップを作らせた。ミューラーは、細菌がふえない酸っぱさになるよう、酢と、トマトにもともとあるペクチン（とろみのもと）の量をつり合わせた。そのために、よく熟したトマトをたっぷり使い、とろみの多いケチャップになった

{{fig:kc-mueller}}

- できたケチャップは、ほかの会社のものより**塩・砂糖・酢が2倍**入っていた（アトラス・オブスキュラ）。1915年ごろまでに、大きなケチャップ会社のほとんどが保存料をやめた。今のケチャップがあまくてすっぱいのは、この「薬なしで長もちさせる」くふうのなごり

{{fig:kc-double}}

### 言い伝え：トマトを食べて見せた男

- 「1820年、ニュージャージー州セーラムの裁判所の階段で、ロバート・ギボン・ジョンソンが、毒だと思われていたトマトを食べて見せた」という話が、多くの百科事典や本にのっている。しかし歴史家のアンドリュー・F・スミスがセーラムの古い新聞や本、手紙を調べたところ、そのできごとの証拠は見つからなかった。ジョンソンは実在の人物だが、話は「作られた言い伝え」だとしている

{{fig:kc-salem-myth}}

- いっぽう、トマトのケチャップのレシピは1812年（ミーズ）には本にのっている。年でくらべると、「1820年にトマトが食べられるとわかって、ケチャップが生まれた」という順番にはならない

{{fig:kc-myth-vs-record}}

### 日本のケチャップ：カゴメ

| 年 | できごと |
|---|---|
| 1899年 | 愛知県の蟹江一太郎（かにえ いちたろう）が、兵役中の上官に「米と麦だけの農業では先がない、西洋野菜に取り組むべきだ」と言われ、トマトなどの西洋野菜を育て始める |
| 1899〜1900年ごろ | トマトは洋食店やホテルでも買い手がつかず、はじめの1〜2年は畑で腐らせた |
| 1902年 | 愛知県農事試験場の技師、柘植権六（つげ ごんろく）から「アメリカではトマトを加工して使う」と教わる。名古屋ホテルで輸入品のトマトソースを1びんゆずってもらい、家族で作り方を考えた |
| 1903年 | 7月、自宅の納屋で「トマトソース」を作り始める。塩も香辛料も入らない、今のトマトピューレーにあたるもの |
| 1908年 | ソース屋の梅澤岩吉商店に教わり、トマトケチャップとウスターソースの製造を始める |
| 1917年 | 商標を登録。軍隊の縁で星のマークを考えたが「陸軍の象徴」として通らず、三角形を2つ重ねた籠目（かごめ）の形にした |

{{fig:ketchup-history}}

- はじめのケチャップは「今ひとつの反応」だったが、1930年ごろにはトマトソースより多く作るようになり、1939年にはトマトソースの約6倍になった（NTTコムウェア COMZINE）

{{fig:kc-japan-grow}}

- 第二次世界大戦中、トマトが足りなくなったフィリピンでは、代わりに**バナナケチャップ**が作られて人気になった

{{fig:kc-banana}}

### みてみよう

- 家のケチャップの「原材料名」を見て、**保存料**が書いてあるか、予想してからさがす。かわりに、酢・砂糖（糖類）・食塩がならんでいるはず。100年前に保存料のかわりをつとめた3つ。ほかの調味料（ソース、ドレッシング）のラベルも、同じ3つがあるか見くらべる

{{fig:kc-look-nopreservative}}

## 見るとわかること

ケチャップは、最初はトマトではなく**魚**のソースだった。イギリスでキノコやクルミのケチャップになり、アメリカでトマトのケチャップになった。日本では、だれも買ってくれなかったトマトを何とか使おうとして生まれた。

## なぜそうなっているか

### 魚 → キノコ → トマト

| 時代 | 場所 | どんなケチャップ |
|---|---|---|
| 数百年前 | 中国 | 魚から作るソースを「ケチャップ（KE-chiap）」と呼び、魚醤（ぎょしょう）のように使った |
| 18世紀 | イギリス | マレー半島やシンガポールを通って伝わり、ローストや揚げ物にしょうゆのようにかけた。マッシュルームや酢漬けのクルミ、アンチョビ（小魚）でも作られた |
| 1812年 | アメリカ | フィラデルフィアの医師で科学者のジェームス・ミーズが、トマトのケチャップのレシピを本にのせる。トマトに砂糖と酢、クローブ・ナツメグ・ジンジャーで味をつけた、今の形 |
| 1876年 | アメリカ | ハインツが「トマトケチャップ」を売り出す。母のレシピの西洋わさびソースの会社がうまくいかずに破産し、新しい会社の目玉商品が必要だった |

- 第二次世界大戦中、トマトが足りなくなったフィリピンでは、代わりに**バナナケチャップ**が作られて人気になった

### 日本のケチャップ：カゴメ

| 年 | できごと |
|---|---|
| 1899年 | 愛知県の蟹江一太郎（かにえ いちたろう）が、軍隊の上官に「米と麦だけの農業では先がない」と言われ、トマトやキャベツなど西洋野菜を育て始める |
| 1899〜1900年ごろ | トマトはホテルや西洋料理店でも買い手がつかず、最初の1〜2年は捨てたり畑で腐らせたりした |
| 1902年 | 県の農事試験場の技師から「アメリカではトマトを加工して使う」と教わる |
| 1903年 | 自宅の納屋でトマトソース（今のトマトピューレに近い、味つけなし）を作り始める |
| 1908年 | トマトケチャップとウスターソースの製造を始める |
| 1917年 | 「カゴメ印」を商標登録。上官との縁で星のマークを出したが、陸軍の印だとして通らず、三角形を2つ重ねた籠目（かごめ）の形にした |

## 3〜5歳むけ

ケチャップは、むかしは さかなの ソースだったよ。

{{fig:ketchup-fish-to-tomato}}

いろんな くにを たびして、トマトの ソースに なったんだ。

にほんでは、うれない トマトを ソースに したよ。

## 6〜9歳むけ

ケチャップは、むかし ちゅうごくで さかなから つくる ソースの なまえだったよ。

イギリスでは キノコや クルミでも つくったよ。アメリカで トマトの ケチャップに なったんだ。

{{fig:ketchup-fish-to-tomato}}

にほんでは、かにえ いちたろうさんが トマトを そだてたよ。でも、だれも かって くれなかったんだ。

そこで、にて ソースに したら つかって もらえたよ。それが ケチャップの はじまりなんだ。

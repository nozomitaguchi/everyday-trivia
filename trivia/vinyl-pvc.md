## 見るとわかること

浮き輪、プールバッグ、テーブルクロス、水道のパイプ、電線の外側。どれも塩化ビニル（塩ビ、PVC）。同じ材料なのに、パイプはかたく、浮き輪はやわらかい。ちがいは、あとから混ぜる「可塑剤（かそざい）」の量。

## なぜそうなっているか

### 材料の6割は「塩」

- 塩ビの重さの約6割（57％）は**塩素**という元素（分子の中の原子の重さの割合）。その塩素は、海水などからとれる塩（塩化ナトリウム）を電気で分けて取り出したもの。食塩そのものがまざっているわけではない。100％石油から作るほかの多くのプラスチックとちがい、石油は残りの4割ほどですむ
- 作り方は、ポリエチレンより1段多い

{{fig:pvc-process}}

| 工程 | 中身 |
|---|---|
| 1. 塩素とエチレンを用意 | 工業用の塩を電気分解して塩素、ナフサを熱分解してエチレン |
| 2. 二塩化エチレンを作る | エチレンと塩素を触媒の入った反応器で反応させる |
| 3. 熱で割る | 二塩化エチレンを数百℃の炉で分解すると、塩ビモノマー（塩化ビニル）と塩化水素ができる |
| 4. 余りも使い切る | 出てきた塩化水素を、空気とエチレンと反応させてもう一度二塩化エチレンにする（オキシ塩素化） |
| 5. つなげる | 塩ビモノマーを水の中で、数気圧・40〜60℃で反応させる（懸濁重合）。直径80〜200μmの粉になる |

- 塩ビモノマーは分子量62.5、沸点がマイナス13.9℃で、ふだんは気体

### かたい塩ビをやわらかくする「可塑剤」

- 塩ビそのものは、かたくてもろい。そのままではパイプや板にしか向かない
- **可塑剤**は、塩ビのくさりのすき間に入りこんで、くさりどうしが引き合う力を弱める油のような物質。重いものを「ころ」の上にのせると動かしやすくなるのと似ている
{{fig:plasticizer}}

- 代表的な可塑剤はフタル酸ジオクチル（DOP）など

| 製品 | 可塑剤の量 |
|---|---|
| パイプ、雨どい（かたい） | 数％ |
| 風呂敷、靴、かばん（やわらかい） | 40〜60％ |

{{fig:pvc-hard-soft}}

- つまり、やわらかいビニール製品の重さの半分近くは、可塑剤

### だれが、どうやって

| 年 | できごと |
|---|---|
| 1872年ごろ | ドイツで塩ビが偶然できたが、かたくてもろく「役に立たない珍しいもの」とされた |
| 1910年代 | ドイツのクラッテが日光で固まった塩ビを見つけ、特許をとったが、製品にはしなかった |
| 1926年 | アメリカ BFグッドリッチ社のワルド・シーモンが、ゴムを金属にくっつける接着剤を研究中、塩ビを沸点の高い溶剤といっしょに加熱した。冷えるとゴムのように弾む、くっつかないゼリーができた。これが可塑剤でやわらかくした塩ビの始まり。本人はのちに「偶然だった」と語っている |
| 1930年代 | グッドリッチ社が「コロシール」の名で売り出す。ドイツではIG社が1931年に「イゲリット」の名で販売 |
| 1941年 | 日本窒素肥料（水俣）が日本で初めて工業生産。商品名「ニポリット」 |
| 1947〜48年ごろ | 日本で、やわらかい塩ビのレインコート、ハンドバッグ、風呂敷、ベルトが小ブーム |
| 1951〜52年 | 農業用の塩ビフィルムの生産が始まる |
| 1964年 | 日本ゼオンなどが、エチレンから作る方法を工業化。それまではカーバイド（石灰と石炭から作る）由来のアセチレンが原料だった |

{{fig:semon-accident}}

- 接着剤を作ろうとして失敗した結果が、やわらかいビニールになった。そのあと日本では、まず塩ビの日用品が「ビニール」として広まったので、あとから来たポリエチレンの袋まで「ビニール袋」と呼ばれるようになった（→[「ビニール袋」は実はビニールではない](plastic-bag-polyethylene.md)）

## 3〜5歳むけ

うきわは、ほんものの ビニールで できて いるよ。

ほんものの ビニールの もとは、しおなんだ。

しおと あぶらを まぜて、つくるよ。

そのままだと、かちかちに かたいんだ。

## 6〜9歳むけ

うきわや プールバッグは、ほんものの「ビニール」で できて いるよ。

ビニールの おもさの はんぶんより おおくは、しおから とった ものなんだ。

ビニールは、そのままだと かたくて、われやすいよ。だから すいどうの パイプに つかうんだ。

そこに あぶらの ような くすりを まぜると、ふにゃふにゃに なるよ。くさりの すきまに はいって、すべりやすく するからなんだ。

{{fig:plasticizer}}

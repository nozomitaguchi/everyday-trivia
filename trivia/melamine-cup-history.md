## 見るとわかること

メラミンという物質は、1834年にドイツの化学者リービッヒが初めて作った。樹脂の材料になるのは、それから約100年後。1900年代のはじめ、熱で固まるプラスチック（フェノール樹脂＝ベークライト）が生まれたが、色が黒っぽい。次の尿素樹脂は明るい色にできたが、熱いお湯に弱い。1935年、スイスのチバ社の2人が、メラミンとホルムアルデヒドで、明るい色にできて、水や熱に強い樹脂の特許を出した。戦争中はアメリカ海軍の船で使われ、戦後のアメリカで、カラフルなメラミン食器が大流行。日本では昭和30年ごろから食器に使われ、学校給食にも入った。

## なぜそうなっているか

### メラミン食器がなかったころ

- 学校給食の食器は、戦前は陶器、戦後はアルマイトが主だった（奈良教育大学紀要、2014年）。札幌市では、1951年（昭和26年）にアルマイトのカップ1つで給食が始まった

{{fig:mc-h-almite}}

- アルマイトは、アルミニウムの表面を電気で酸化させて、さびにくい膜をつけたもの。理化学研究所の植木榮らが1923年に特許を出願し、宮田聰が膜の小さな穴をふさぐ「蒸気封孔法」を見つけて1929年に特許になった。理研は、アルマイトの弁当箱を工業化した（理化学研究所）

{{fig:mc-h-riken}}

- アルマイトの困りごと：熱が伝わりやすい。汁用の食器で調べると、アルマイトはお湯の温度がどんどん下がり、お湯を入れた直後は、底の温度が手で持つのにちょうどよい温度（37〜47℃）を大きくこえた。プラスチックや木のお椀は、さめにくかった（奈良教育大学紀要）

{{fig:mc-h-almite-hot}}

### 少しずつ今の形にした人たち

| 年 | だれが・どこで | 何をしたか |
|---|---|---|
| 1834年 | リービッヒ（ドイツ） | メラミンを初めて作る |
| 1907年 | ベークランド（アメリカ） | フェノール樹脂（ベークライト）の特許を出願。熱で固まるが、色は黒っぽい |
| 1930年代 | 各国 | 尿素樹脂が人気に。明るい色にできるが、熱いお湯に弱い |
| 1935年 | ウィドマーとフィッシュ（チバ社、スイス） | メラミンとホルムアルデヒドの樹脂、セルロース入り成形品の特許 |
| 1940年 | アメリカン・シアナミド社 | 「メルマック」の名前を使いはじめる |
| 1953年 | ラッセル・ライト（デザイナー） | 家庭用のメラミン食器「レジデンシャル」 |

{{fig:mc-h-people}}

- 1834年、リービッヒは、チオシアン酸の塩（チオシアン酸カリウムと塩化アンモニウム）を熱した残りから、メラミンを初めて取り出して記録した（国際がん研究機関、chemie.de）

{{fig:mc-h-liebig}}

- 1907年7月13日、ベークランドがフェノール樹脂の特許を出願した（1909年登録）。じょうぶにするために中にまぜるものが見えないよう、黒っぽい色で作られることが多かった。そのあと出た尿素樹脂は、もっと明るい色にできた（Wikipedia「Bakelite」）

{{fig:mc-h-bakelite}}

- 尿素樹脂は1932年ごろから1950年ごろまで大人気だった。色はきれいだが、水、とくに熱いお湯に弱い。のちに、性質のよいメラミン樹脂に置きかわった（オランダ文化遺産庁）。メラミン樹脂は尿素樹脂より水に強く、かたく、じょうぶで、1950年代から、成形した皿や食品の容器で尿素樹脂に取ってかわった（ブリタニカ）

{{fig:mc-h-urea-weak}}

- 1935年9月28日、スイス・バーゼルのチバ社のグスタフ・ウィドマーとヴィリ・フィッシュが、メラミンとホルムアルデヒドをつないだ樹脂をスイスで出願した。アメリカの特許（1943年登録）には、熱と圧力で固めた成形品と、セルロースの充填材をまぜた成形材料が書かれている

{{fig:mc-h-ciba}}

- アメリカン・シアナミド社は、1940年12月12日から「メルマック（Melmac）」という名前を合成樹脂に使いはじめた（米国の商標記録）

{{fig:mc-h-melmac}}

### 船の上から、家の台所へ

- 第二次世界大戦中、アメリカ海軍の一部の船で、じょうぶな食器として使われた（TIME、2008年）

{{fig:mc-h-navy}}

- デザイナーのラッセル・ライトは、はじめメラミンの特許を持つアメリカン・シアナミド社と食器を作ろうとしたがうまくいかず、別の会社と組んだ。1953年にデザインした「レジデンシャル」は、ノーザン・インダストリアル・ケミカル社が作り、1957年までに訪問販売で400万ドル売れた。プラスチックの食器は、はじめ食堂などの施設用で、のちに家庭に広がった（ブルックリン美術館）

{{fig:mc-h-wright}}

- 1950年代、カラフルなメラミンの皿やボウルはアメリカの台所の定番になった。でも、傷やしみがつきやすく、1970年代には人気が下がり、陶磁器やガラスにもどる家が多かった（TIME）

{{fig:mc-h-decline}}

### 日本では

| 年 | できごと |
|---|---|
| 昭和30年（1955年）ごろ | メラミン樹脂が食器に使われはじめる |
| 1964年 | 日産化学が富山工場でメラミンの生産を始める（2022年に停止） |
| 昭和40年代（1965〜1974年） | 絵付けの技術ができ、急に広まる |
| 1970〜1980年代 | 学校給食に、ポリプロピレンやメラミンのプラスチック食器が入る |
| 1990年代〜 | ポリカーボネート、強化磁器などへ |

{{fig:mc-h-japan}}

- 給食でいつメラミンが入ったかは、資料によってちがう。「1970年代にメラミンのランチ皿が普及」とする研究（関西大学、2019年）も、「1970年代の終わりからプラスチック」とする研究（奈良教育大学、2014年）もある。札幌市のように、アルマイト→ポリプロピレン（1972年）→ステンレス（1977年）→磁器（1999年）と、メラミンを通らなかった町もある

{{fig:mc-h-lunch}}

- 1980年代には、ポリプロピレンやメラミンからホルムアルデヒドが溶け出す問題が取り上げられ、1990年代にはポリカーボネートからのビスフェノールAが問題になった。いまは強化磁器なども広まっている（関西大学、奈良教育大学）

{{fig:mc-h-concern}}

### みてみよう

- 給食や病院の食事の写真、園や家の食器を見て、それがアルマイト（銀色の金属）か、メラミン（つやのある色つき）か、磁器（白くて重そう）かを予想する。おうちの人に、子どものころの給食の食器が何だったかを聞いてくらべる
